# Mahvex Template

> A clean, modern, minimal HTML/CSS template for developers and creators.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

## Features

- Clean & minimal design — inspired by Linear and Vercel
- Dark theme — easy on the eyes
- Responsive — works on mobile, tablet, and desktop
- No frameworks — pure HTML, CSS, and vanilla JavaScript
- Fast & lightweight — no dependencies, no build step
- Easy to customize — CSS variables for colors and spacing

## Project Structure

mahvex-template/

## Customization

Edit CSS variables in `assets/css/style.css`:

```css
:root {
  --bg: #0a0a0a;
  --text: #f5f5f5;
  --accent: #8b5cf6;
  --radius: 12px;
}
```

## Quick Start

```bash
git clone https://github.com/Mahvex/mahvex-template.git
cd mahvex-template
python3 -m http.server 8000
```

Then open http://localhost:8000
